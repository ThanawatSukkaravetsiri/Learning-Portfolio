What I Built

เว็บไซต์ที่ผมสร้างก็จะเกี่ยวกับสิ่งที่ผมได้เรียนรู้ในห้องเรียนและบนอินเตอร์เน็ต ส่วนประกอบที่สำคัญก็จะมี header, main, section, footer ซึ่งช่วยแบ่งโครงสร้างและเนื้อหาของเว็บไซต์ให้แยกเป็นส่วนๆ. มี client และ server เกิดขึ้นแล้ว เพราะ live preview เครื่องของผมสามารถทำหน้าที่เป็นทั้ง client และ server โดย browser ทำหน้าที่เป็น client และส่ง HTTP request ไปยัง Live Preview ที่ทำหน้าที่เป็น server จากนั้น server จะส่ง HTTP response กลับมาให้ browser เพื่อแสดงเว็บไซต์.

How I Built It

  • 1. ค้นหารูปภาพตัวอย่างบนอินเตอร์เน็ตว่าจะออกแบบยังไง
  • 2. ลองเอาตัวอย่างรูปภาพที่สนใจแล้วปรับแต่งให้เข้ากับสิ่งที่เรียน
  • 3. ลองทดสอบบนbrowserเพื่อแก้ไขขนาด
